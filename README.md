# featurevisor-example-ruby

A small Ruby application showing how to use the [Featurevisor Ruby SDK](https://github.com/featurevisor/featurevisor-ruby).

Learn more about Featurevisor [here](https://featurevisor.com).

It fetches a production datafile, creates a Featurevisor instance with customer context, then evaluates a flag, a variation, feature variables, and global variables.

## Installation

```sh
bundle install
```

## Run the example

```sh
bundle exec ruby app.rb
```

The application evaluates `commerce_platform`, `checkout_experience`, `max_items`, `payment_methods`, `serviceEndpoints`, and `supportContact` from this datafile:

```text
https://featurevisor-example-cloudflare.pages.dev/production/featurevisor-sdk-v3.json
```

Expected output:

```text
Commerce platform enabled: true
Checkout variation: express
Maximum checkout items: 25
Payment methods: ["card", "wallet"]
Service endpoint: https://api.eu.example.com (timeout: 1200 ms, retries: 4)
Support contact: support-nl@example.com
```

Change the context in `app.rb` to see how Featurevisor selects different rules, variations, and global variable overrides.
